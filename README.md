# Jayasimbu Jayamani — Full Stack & AI Application Developer Portfolio

Modern portfolio built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

## Features
- **Portfolio Sections:** Hero (with FastAPI code preview), Stats, About, Filterable Skills, Featured Projects (`LINKUP`, `VLM LLaVA`, `MyFitness Hub`), Services, Experience, Education, Certifications, Philosophy, and Contact.
- **Interactive AI Lab:** Live simulated demos for LINKUP ATS matching, VLM Invoice Q&A, and MyFitness Gemini routine generation.
- **Resume & Architecture Modals:** Printable/PDF-ready resume preview and detailed project architecture modals.
- **OS Mode:** Optional interactive desktop OS view (`DesktopOS`).

## Commands

```bash
npm run dev     # Start local dev server at http://localhost:3000
npm run build   # Build production bundle
npm run lint    # Run ESLint
```
